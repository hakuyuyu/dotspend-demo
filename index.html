How DotSpend enforces this for real

  • Pre-aggregated ledger — one row per (agent, period). Budget checks are O(1), no matter how many tasks the dot runs.
  • Per-agent caps — daily + hourly, per dot. Unknown agent? Fail closed: blocked by default, never silently allowed.
  • Hard cutoffs — a breached cap raises BudgetExceeded → HTTP 402. The task stops; the bill can't grow.
  • Kill switch — one call halts every agent at once. Wake up to a receipt, not a surprise.
  • One pricing file — every rate lives in pricing.py. Update prices once; the whole kit follows.
